# CURA Skincare Website

A responsive luxury skincare storefront with an editorial, apothecary-inspired visual direction.

## Run locally

Open `index.html` directly in a modern browser, or use Vite:

```bash
npm install
npm run dev
```

## Production build

```bash
npm install
npm run build
```

## Included interactions

- Responsive desktop and mobile navigation
- Product quick views
- Product search
- Interactive shopping cart and quantity controls
- Newsletter confirmation state
- Scroll-based reveal animation

## Project structure

- `index.html` — storefront markup
- `styles.css` — responsive visual system
- `main.js` — product, search, cart, menu, and modal interactions
- `assets/` — CURA product and campaign imagery
